# Práctica · Introducción a CSS

1. **Las tres formas:** haz una página con un párrafo y píntalo de azul de tres maneras distintas (en línea, `<style>` y `.css` externo). Comprueba cuál gana si usas colores diferentes en cada una.
2. **Selectores:** crea tres párrafos; dale a uno la clase `.importante` (en rojo y negrita), a otro el id `#unico` (con fondo amarillo) y deja el tercero normal.
3. **Selector descendiente:** pon un `<a>` dentro de un `<nav>` y otro fuera. Haz que solo el de dentro del `nav` sea naranja con `nav a { }`.
4. **Modelo de caja:** una caja de 300px de ancho con `padding: 20px`, `border: 5px solid` y `margin: 30px auto`. Calcula a mano su ancho total **con** y **sin** `box-sizing: border-box`.
5. **Tarjeta de presentación:** `div` con tu nombre (`h2`), tu profesión (`p`), fondo claro, borde redondeado (`border-radius: 10px`) y centrada en la página.
6. **Caza el error:** quita un `;` de una declaración y observa qué deja de funcionar.

✅ Pista: abre DevTools (`F12`) → pestaña *Elements* → *Styles* para ver qué reglas se aplican y cuáles quedan tachadas.
