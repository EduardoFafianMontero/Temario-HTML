# Práctica · Introducción a HTML

Retos para hacer **sin mirar** el ejemplo comentado. Cada uno en su propio archivo `.html`.

1. **Página "Sobre mí".** Escribe la estructura mínima desde cero y pon tu nombre como título y un párrafo que te describa.
2. **Cambia el `<title>`** y comprueba que cambia el texto de la pestaña.
3. **Rómpelo a propósito:** quita `<meta charset="UTF-8">` y escribe "ñ á é ü". Mira si se ven bien (puede depender del navegador) y vuelve a ponerlo.
4. **Cierre mal hecho:** escribe `<p><strong>hola</p></strong>` y abre DevTools (`F12` → pestaña *Elements*) para ver cómo lo "arregla" el navegador.
5. **Explícalo con tus palabras:** en un comentario `<!-- -->` escribe qué hace cada etiqueta de la estructura mínima.

✅ Cuando los hagas, anota aquí qué te costó más.
