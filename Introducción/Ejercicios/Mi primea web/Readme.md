# Mi primera web

## 📌 Sobre este ejercicio

Primer contacto con HTML: estructura mínima de un documento y las etiquetas base que lleva cualquier página.

## 🧩 Qué incluye

- `<!DOCTYPE html>` — Indica al navegador que el documento es HTML5.
- `<html lang="en">` — Elemento raíz del documento; `lang` indica el idioma del contenido.
- `<head>` — Metadatos de la página (no visibles): `charset` (codificación de caracteres), `viewport` (adaptación a móvil) y `<title>` (el que aparece en la pestaña del navegador).
- `<body>` — Contenido visible: un título con `<h1>` y un párrafo con `<p>`.

## 💻 Cómo verlo

Abrir `index.html` directamente en el navegador, o usar la extensión **Live Server** de VS Code.

## 📝 Notas

- `<h1>` se usa para el título principal de la página — solo debería haber uno por página.
- `<p>` se usa para párrafos de texto normal.
