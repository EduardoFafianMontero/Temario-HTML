# Introducción a HTML

## 📌 Sobre esta carpeta

Primeros pasos con HTML: estructura básica de un documento, las etiquetas principales (`html`, `head`, `body`) y cómo se ve una página web sencilla en el navegador.

Está dividida en dos subcarpetas:

- **[Ejercicios/](./Ejercicios)** — Prácticas que voy haciendo sobre lo visto en teoría.
- **[Teoria/](./Teoria)** — Apuntes y notas de los conceptos de este tema.

## 📂 Ejercicios

- **[Mi primera web](./Ejercicios/Mi%20primera%20web)** — Estructura básica de un documento HTML: `<!DOCTYPE html>`, `<html>`, `<head>` (con `meta charset`, `meta viewport` y `<title>`) y `<body>` con un título (`<h1>`) y un párrafo (`<p>`).
