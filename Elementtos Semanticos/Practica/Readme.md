# Práctica · Elementos semánticos

1. **Esqueleto:** crea una página con `header`, `nav`, `main` y `footer`, sin `div`.
2. **Dos artículos** dentro de `main`, cada uno con título y fecha en `<time>`.
3. **Aside** con tu presentación a un lado, usando `display: flex`.
4. **Section:** una sección "Proyectos" con su `h2`.
5. **Figure:** una imagen con `figcaption`.
6. **Reescribe** una página tuya antigua cambiando los `div` por etiquetas semánticas.
7. **Pregunta:** ¿qué pasa si pones dos `<main>`? Escríbelo en tus palabras.

✅ Pista: el contenedor de `main` y `aside` es el único `div` necesario, y solo para el estilo.
