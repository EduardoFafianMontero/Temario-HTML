# Práctica · Instalación de herramientas

1. **Instala VS Code** y abre una carpeta `Temario-HTML` con `code .` desde la terminal.
2. **Instala las 4 extensiones** de la tabla (Live Server, Prettier, Auto Rename Tag, HTML CSS Support).
3. Crea un `index.html` vacío, escribe `!` y pulsa `Tab`. **Cambia `lang="en"` por `lang="es"`** y pon un `<title>` propio.
4. Abre la página con **Live Server**, cambia un texto, guarda y comprueba que se actualiza sola.
5. Escribe `ul>li*5` + `Tab` y rellena los 5 elementos con tus 5 atajos favoritos.
6. Desordena la sangría del archivo a propósito y arréglalo con `Alt + Shift + F`.
7. Comenta y descomenta una línea con `Ctrl + /`.

✅ Cuando termines, anota qué atajo te ha ahorrado más tiempo.
