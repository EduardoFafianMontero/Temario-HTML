# Práctica · Elementos básicos

1. **Mi presentación:** un `h1` con tu nombre, un `h2` por sección (*Estudios*, *Aficiones*) y un párrafo bajo cada una.
2. **Una dirección postal** escrita en un solo `<p>` usando `<br>` para separar las líneas.
3. **Receta de cocina:** título, un párrafo de introducción y una frase en `<strong>` con la advertencia más importante.
4. **Cita famosa** con `<blockquote>` y debajo, en un `<p>`, el nombre del autor.
5. **Código en la web:** explica en un párrafo cómo se escribe un `<h1>` usando `<code>` y `&lt;` / `&gt;`.
6. **Galería mínima:** tres imágenes con su `alt` y distinto `width`. Luego **rompe a propósito** una ruta de `src` y mira qué se ve.
7. **Comentarios:** deja un `<!-- -->` explicando cada bloque de tu página.

✅ Pista: no uses `<br>` para separar párrafos ni `<h1>` para "hacer letra grande".
