# Práctica · Links

1. **Dos páginas:** crea `index.html` y `contacto.html` enlazadas entre sí, ida y vuelta.
2. **Pestaña nueva:** añade un enlace a tu perfil de GitHub que se abra en pestaña nueva, con el `rel` correcto.
3. **Índice con anclas:** una página con 3 secciones largas (`h2` con `id`) y, arriba, un índice que salte a cada una. Añade "Volver arriba" al final de cada sección.
4. **Contacto:** un enlace `mailto:` y otro `tel:`.
5. **Estados:** da estilo a los 4 estados (`link`, `visited`, `hover`, `active`) con colores distintos. Luego **cambia el orden** y observa qué estado deja de verse.
6. **Menú:** tres enlaces en línea (`Inicio`, `Temario`, `Contacto`) sin subrayado, que se subrayen solo al pasar el ratón.
7. **Imagen-enlace:** una imagen (`<img>`) dentro de un `<a>` que lleve a otra página.
8. **Caza el error:** escribe mal a propósito un `href` y comprueba qué pasa al pulsarlo.

✅ Pista: `a:hover` con `text-decoration: underline;` y el resto con `none`.
