# Práctica · Formularios

1. **Contacto:** nombre, correo y mensaje con sus `label` enlazados.
2. **Obligatorios:** haz `required` el nombre y el correo y prueba a enviar vacío.
3. **Contraseña** de mínimo 8 caracteres.
4. **Select** con 4 países.
5. **Radio:** elige entre 3 opciones y comprueba qué pasa si cambias un `name`.
6. **Checkbox:** 3 aficiones a la vez.
7. **Fieldset y legend** para agrupar los datos personales.
8. **Estilo:** deja el formulario en una columna de 400px, con campos a todo el ancho.
9. **Get vs post:** cambia `method` a `get` y mira cómo cambia la URL al enviar.

✅ Pista: para ver la URL, usa `action=""` en vez de `#`.
