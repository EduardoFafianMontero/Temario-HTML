# Párrafos

## 📌 Sobre este ejercicio

Práctica de la etiqueta `<p>` para párrafos de texto, combinada con `<br>` para forzar un salto de línea dentro del mismo párrafo.

## 🧩 Qué incluye

- `<h1>` — Título del ejercicio ("Elemenos de parrafo").
- `<p>` — Un párrafo con dos datos (nombre y edad).
- `<br/>` — Salto de línea manual *dentro* del párrafo, sin cerrarlo ni crear uno nuevo.
- `<!-- comentario -->` — Comentario HTML explicando qué hace `<br/>` (no se muestra en el navegador).

## 💻 Cómo verlo

Abrir `index.html` directamente en el navegador, o usar la extensión **Live Server** de VS Code.

## 📝 Notas

- `<br>` es una etiqueta "vacía" (no lleva contenido ni etiqueta de cierre propia) — se puede escribir como `<br>` o `<br/>`.
- Los comentarios (`<!-- -->`) sirven para dejar notas en el código sin que afecten a lo que ve el usuario.
