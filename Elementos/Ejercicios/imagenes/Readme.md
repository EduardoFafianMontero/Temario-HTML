# imagenes

## 📌 Sobre este ejercicio

Uso de la etiqueta `<img>` para insertar imágenes locales, guardadas en la subcarpeta `src/`.

## 🧩 Qué incluye

| Atributo | Para qué sirve |
| :--- | :--- |
| `src` | Ruta al archivo de la imagen (relativa, dentro de `src/`) |
| `alt` | Texto alternativo — se muestra si la imagen no carga, y lo usan los lectores de pantalla |
| `width` | Ancho de la imagen en píxeles |

Se insertan 3 imágenes: `html5.png`, `css3.png` y `javascript.png`.

## 💻 Cómo verlo

Abrir `index.html` directamente en el navegador, o usar la extensión **Live Server** de VS Code.

## 📝 Notas

- ⚠️ En la imagen de CSS falta un espacio entre `src="src/css3.png"` y `alt="Logo css"` — al quedar pegados (`png"alt=`), conviene revisarlo para que no dé problemas.
- `alt` no es opcional por estética: es importante para accesibilidad y SEO, así que está bien que esté en las 3 imágenes.
