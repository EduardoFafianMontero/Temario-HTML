# Títulos

## 📌 Sobre este ejercicio

Práctica de las 6 etiquetas de encabezado que ofrece HTML, de mayor a menor jerarquía.

## 🧩 Qué incluye

| Etiqueta | Uso en el ejercicio | Jerarquía |
| :--- | :--- | :--- |
| `<h1>` | Titulo 1 | Máxima — el título principal de la página |
| `<h2>` | Titulo 2 | Subtítulo de primer nivel |
| `<h3>` | Titulo 3 | Subtítulo de segundo nivel |
| `<h4>` | Titulo 4 | Subtítulo de tercer nivel |
| `<h5>` | Titulo 5 | Subtítulo de cuarto nivel |
| `<h6>` | Titulo 6 | Mínima — el título menos destacado |

También incluye un `<p>` de introducción antes de los títulos.

## 💻 Cómo verlo

Abrir `index.html` directamente en el navegador, o usar la extensión **Live Server** de VS Code.

## 📝 Notas

- Cuanto más bajo el número (`h1`), más grande y destacado se ve por defecto.
- Solo debería haber un `<h1>` por página — el resto se usan para organizar el contenido en subsecciones, no para elegir un tamaño de letra.
