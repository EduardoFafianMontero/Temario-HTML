# Links

## 📌 Sobre este ejercicio

Uso de la etiqueta `<a>` para crear enlaces: uno externo (a otra web) y uno interno (a otra página del propio proyecto).

## 🧩 Qué incluye

| Enlace | Atributo | Para qué sirve |
| :--- | :--- | :--- |
| A Google | `href="http://www.ggoogle.com"` | Enlace externo, a una web fuera del proyecto |
| | `target="_blank"` | Abre el enlace en una pestaña nueva en vez de sustituir la página actual |
| A `html.html` | `href="html.html"` | Enlace interno, a otro archivo del mismo proyecto (ruta relativa) |

## 💻 Cómo verlo

Abrir `index.html` directamente en el navegador, o usar la extensión **Live Server** de VS Code.

## 📝 Notas

- ⚠️ El `href` del enlace a Google tiene un typo: `www.ggoogle.com` (doble "g"). Así tal cual no lleva a ningún sitio.
- Sin `target="_blank"`, un enlace se abre por defecto en la misma pestaña.
